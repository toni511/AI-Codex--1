# Jenga Web App

This repository contains a simple web application that lets you play a basic Jenga game in your browser. The game uses the [Matter.js](https://brm.io/matter-js/) physics engine.

## How to Run

Open `webapp/index.html` in a modern web browser. You can simply double-click the file or serve it using any static file server. Click and drag blocks to move them. Use the **Reset** button to rebuild the tower.
